1. create_small_world_network.m file creates small world network from ring lattices using Watts Strogatz algorithm.

2. WattsStrogatz.m file is the matlab file found on matlab page for creating small world network from ring lattices.

3. small_world_network1.m file creates many small world network realizations from a ring lattice of N nodes with order m. N and m can be modified. Similarly, the number of initial conditions- monte_carlo_simulation_num be altered and we find how the basin size of consensus state changes with the rewiring probability.
